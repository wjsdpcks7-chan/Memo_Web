# 메모 Web 제작
**소개**: 간단하게 메모하고 저장된 메모 리스트 및 내용 확인하는 프로그램

**목적**: FastAPI 및 HTML 숙지를 위한 과제

## 서버 실행 방법
1. **저장소 받기**: `https://github.com/wjsdpcks7-chan/Memo_Web.git`

2. **가상환경 생성 및 활성화**: `python3 -m venv venv`
| `source venv/bin/activate`

3. **패키지 설치**: `pip install -r requirements.txt`

4. **서버 실행**: `uvicorn main:app --reload`

5. **브라우저 접속**: `http://127.0.0.1:8000`

## API 명세
### 메모저장
- **메서드 / 경로**: POST /memos
- **요청 바디**: 메모 내용 `{ "content" : "내일 회의 자료 준비" }`
- **성공 응답(201)**: `{ "id" : 3 }`
- **실패 응답**
    - 바디에 content가 없을 때: 422
    - 서버에서 파일 쓰기 중 예외 발생: 500

### 목록조회
- **메서드 / 경로**: GET /memos
- **요청 바디**: 없음. 
- **성공 응답(200)**:
    - id 오름차순 `[1, 2, 3, 4, 5]`
    - 메모가 없으면 빈 배열
### 본문조회
- **메서드 / 경로**: GET /memos/{id}
- **요청 바디**: 없음. 조회할 메모의 id는 경로에 넣는다. ex) GET  /memos/3
- **성공 응답(200)**: `{ "id": 3, "content": "내일 회의 자료 준비" }`
- **실패 응답**
    - 해당 id의 파일이 없을 때 : 404

## 다음 ID를 정하는 방식
- **방식**: 파일 개수 + 1
- **설명**: 파일 삭제가 없다고 가정. 우선 간단히 기능 구현을 위해 단순한 방식 채택
- **개선 방안**: 파일 id 중에 제일 큰 id + 1로 id 생성 방식
